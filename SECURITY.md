# Security Policy

fear.social takes security reports seriously. Send suspected vulnerabilities, abuse, account compromise, or privacy concerns to contact@fear.social.

Please include:

- The affected URL, account area, or API route.
- Steps to reproduce the issue.
- The expected behavior and actual behavior.
- Any screenshots, request IDs, or timestamps that help us verify the report.

Do not access, modify, delete, or disclose another user's data while testing. Do not run denial-of-service testing, automated scanning at high volume, social engineering, spam, or destructive testing against the production service.

Security is an ongoing process. The production app uses HTTPS, security headers, server-side validation, session cookies, password hashing, rate limiting, and logging, but no internet service can guarantee absolute protection against every possible attack.
